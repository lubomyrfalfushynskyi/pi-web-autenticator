# Changelog

## 0.3.0 — 2026-09-27

- Added local transport configuration validation and an unauthenticated origin
  diagnostic that reports HTTP reachability without sending the API key or
  invoking authentication/challenge endpoints.
- Added tests for healthy, server-error and network-failure diagnostic results.
